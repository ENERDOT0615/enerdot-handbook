- 참여 가능한 토픽방을 찾아 직접 들어갈 수 있어요.
- 모든 인원이 참여해야 하는 토픽방: **에너닷_공지사항**, **에너닷_채팅**

## 출/퇴근 기록
! 출퇴근은 입구의 지문 단말기로만 기록해요. 모바일/웹으로는 출퇴근 기록이 안 돼요.
- 기록은 플렉스에 자동 연동되고, 남은 퇴근시간과 주간 근무 현황을 플렉스에서 볼 수 있어요.
- 외부에서 퇴근해야 하면 모바일 퇴근 버튼을 누르면 승인 요청이 생성되고, 그룹장 승인 후 근무일정이 생성돼요.
- **오전 6시~10시**: 출근 화면이 상시 노출되고, 지문 태그 시 최초 출입 시간이 출근으로 기록돼요.
- **오전 10시~퇴근**: 퇴근 시 숫자키 3번(퇴근)을 누르고 지문을 태그해요.
- 반차/시간차 사용 시에는 직접 1번(출근) 또는 3번(퇴근)을 누르고 지문을 태그해요.
- 내 출퇴근 내역은 ‘근무’ 메뉴에서 확인해요.
## 출/퇴근 기록 누락 수정
1. 하단 ‘일정’ 탭 클릭
2. 근무일정이 누락된 날짜 선택
3. 근무 시간 수정 후 승인 요청
## 시간외근무 신청 (연장/야간/휴일)
- 연장근무 후 지문으로 퇴근을 찍으면 모바일 앱에서 연장근무 승인 단계로 넘어가요.
! 연장근무는 1시간 이상 근무한 건부터 신청할 수 있어요.
1. 퇴근 버튼 클릭 (근무 사유는 최대한 상세하게)
2. 시간외근무 신청 후 사후보고서 제출 (워크플로우 > 문서 작성 > 사후보고서 작성)
3. 연장근무 승인과 사후보고서 승인이 모두 완료된 건만 월말에 취합해 정산해요.
! 신청과 사후보고서 중 하나라도 빠지면 정산에서 제외되고 이월도 안 돼요.
## 휴가 등록
- 에너닷은 **승인 없는 연차 제도**를 운영해요. 단, 업무와 일정에 피해가 없도록 조율하고 소속 팀장에게 미리 휴가 일정을 공유해 주세요.
1. 대시보드에서 ‘휴가 등록’ 클릭
2. 사용할 휴가와 연차/반차 단위, 날짜 선택
3. 휴가 유형 선택
- 경조사 휴가는 신청한 일수만큼 부여돼요. 신청 시 우측 상단 정보 아이콘에서 항목별 일수와 증빙을 확인한 뒤 신청해 주세요.
## 외근/출장 신청
! 외근/출장은 사전 신청 후 수행해요.
1. 하단 ‘일정’ 탭에서 날짜 선택
2. 외근 또는 출장 유형 선택, 수행 시간 기입
3. 사유 상세 기입
- 출장은 9시~6시로 등록하고 별도 출퇴근 기록은 하지 않아요. 출장은 간주근로라 연장/야간/휴일 근무에 해당하지 않아요.
- 외근은 대략적인 수행 시간을 기입해요.
- **근무 중 긴급 외근/출장**: 진행 중인 근무 선택 → 시작 시점에서 ‘변경’ → 근무 유형 선택 → 퇴근 버튼 후 사유 기입해 승인 요청. 당일 업무 종료를 눌러야 승인 절차로 넘어가고, 사유가 없으면 일반 근무로 전환돼요.
- **1박 이상**은 웹에서만 등록돼요: ‘근무’ → ‘추가하기’ → ‘반복 일정’ → 기간 입력(출장은 9~6시 고정) → 반복 요일은 선택하지 말고 등록 후 사유 기입.
## 재직증명서/경력증명서
- 별도 신청 없이 자동 발급돼요.
- PC: 내 프로필 > 우측 ‘증명서 발급’
- 모바일: 하단 더보기 > ‘문서, 증명서’ > ‘발급 신청’
## 캘린더 연동
- 대시보드 ‘캘린더 연결’에서 구글캘린더를 연동하면 근태 체크 때 그날 일정을 함께 볼 수 있어요.
- 캘린더 상단 메뉴에서 동료/조직 일정과 구글캘린더 구독을 골라 볼 수 있어요.
## 워크플로우 (전자결재)
- 구매 신청부터 거래처 사업지원까지 모두 워크플로우로 신청해요. 유형별 승인권자·처리 시간·첨부서류를 확인 후 제출하고, 긴급 건은 담당자에게 잔디로 꼭 알려주세요.
- 구매 신청: 신청인 이름·연락처로 주문되고, 배송 조회는 신청인이 직접 확인해요.
- 문서 날인: 선 날인 시 전자계약 선택 가능(거래처 사전 동의 필요).
- 동호회 지원금은 워크플로우의 ‘환급신청’, 직무발명·경조 신청(거래처 포함)도 워크플로우로 해요.
- 제출한 문서의 진행 상황은 ‘내 문서함’에서 확인해요.

- 업무 효율을 위해 ChatGPT (Team Workspace)를 **부서별 공유계정**으로 지원해요.
- 사용이 필요하면 **flex > 워크플로우 > 계정 신청**으로 신청해 주세요.
## 이용 규칙
- 일회성 검색은 꼭 상단 우측 ‘임시(temporary)’ 채팅을 켜고 입력해요. (웹, 모바일 모두)
- 실무자별·주제별 대화 이력은 ‘프로젝트’로 관리해요. 프로젝트 생성/삭제 권한은 각 계정 담당 그룹장에게 있어요.
- 유료 버전도 입력 한도가 있으니 여러 명이 함께 쓸 수 있도록 무분별한 사용을 자제해 주세요.
! 개인 용도(예: ‘지브리 스타일로 만들어줘’)나 업무 무관·상업적 용도로 쓰면 계정이 즉시 비활성화돼요.
## 이용 시 유의사항
- 회사 또는 개인정보(직원·고객사 이름, 연락처 등) 입력 금지
- 다자간 계약서, 합의서 등 법적 효력이 있는 문서 업로드 금지
- 제품 사진(하드웨어/소프트웨어 이미지) 업로드 금지
- 보안 문서(시스템 구조, 서버 정보, 보안 정책 등) 업로드 금지
- 서버 IP, ID, PW 등 세부 소스코드 입력 금지
- AI 생성 콘텐츠의 저작권·법적 기준을 지키고, 상업적 사용 전 허가 여부를 검토해요.
- ChatGPT는 틀린 정보를 만들 수 있으니 출처를 꼭 확인한 뒤 외부에 공유해요.
- 보안을 위해 계정 비밀번호는 분기별(또는 90일 이내) 바뀔 수 있고, 대화 기록도 삭제될 수 있어요.
