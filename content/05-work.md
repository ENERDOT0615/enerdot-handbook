## 신청 시 유의사항
! **사전 승인**이 원칙이고, **사후보고서 승인**까지 모두 끝나야 익월 급여에 정산돼요. (플렉스 워크플로우 → 시간외근무 보고서 작성)
- 보고서는 수행일로부터 **영업일 5일 이내** 작성·승인된 건만 수당에 반영돼요. (미승인 시 자동 이월)
- 연장근무는 **1시간 이상**부터 신청할 수 있고, **30분 단위로 절사**해 반영해요.
- 인정 유형이 아니면 승인권자 판단으로 거부될 수 있어요.
- 모든 시간외근무는 **본사에서 수행**하는 게 원칙이에요(야간/휴일 포함, 출퇴근 기록·사전 승인·사후보고서 필수).
- 출장은 간주근로라 연장근로에 해당하지 않아요.
- 반차·반반차 사용 후 소정근로시간 안에서 일한 건 연장근무가 아니에요. (예: 반차 후 오후 2시~8시 근무 = 소정근로 6시간)
- 연장근무 중 휴게시간 권장: 2시간 이하는 생략, 2~4시간은 15분 내외, 4시간 초과는 30분 이상(필수). 휴게시간은 지급 대상 시간에서 빠질 수 있어요.
## 인정 유형
- 정규 업무 외 긴급 처리가 필요한 경우
- 외부 거래처와의 비정규 시간 미팅 및 식사
- 장애·사고·고객지원 대응, 전화/보고/긴급출동 등 실질적 사고 대응
- IT/기술팀의 야간·휴일 서버 관리 등 (본사 근무 시)
- 고객 불만, 기술지원 등 비근무시간 응대
- 기타 상급자 지시 등 명확한 근무 사유가 있는 경우
## 불인정 유형
- 상급자의 사전 승인 없는 자발적 잔업
- 잡담, 인터넷 서핑 등 비업무 활동을 포함한 연장근무
- 지시 내용과 객관적 자료가 없는 외근/내근 연장근무
- 본인 업무가 아닌 타인 업무를 돕다 늦게 퇴근한 경우
- 지시 없이 반복·동일 업무를 위한 습관적 연장근무
## 모성보호
- 임신 중인 직원은 연장/야간/휴일 근무를 할 수 없어요.
- 출산 후 1년 미만 직원은 연장근무가 1일 2시간, 1주 6시간으로 제한돼요.

## 왜 필요한가요?
- 채널이 너무 많고, 끝난 프로젝트 채널이 방치되고, 이름 형식이 제각각이고, 주체 부서가 불명확해서예요.
## 채널 유형
| Prefix | 언제 쓰나요? | 예시 |
| 부서_ | 조직별 상시 운영 채널 | PO_엔비전_CS요청처리 |
| 문의_ | 다른 팀에 요청 | 문의_COS실 |
| 협업_ | 여러 팀이 함께 작업 | 협업_엔비전_페이지제작 |
| TF_ | 대표 승인 중요 과제 | TF_사업개발_KSGE2026 |
| PJT_ | 단기 프로젝트 (1~3개월) | PJT_홈페이지 리뉴얼 |
| 에너닷_ | 전사 공통 (공지/맛집) | 에너닷_공지사항 |
## 이름 짓는 규칙
- **필수**: Prefix 사용 / **권장**: 언더바(_) 구분 / **금지**: 대괄호 [ ]
- 이모지는 에너닷_ 채널에서만 써요.
- 좋은 예: PO_엔비전_청구관리, 문의_에너지금융, 협업_엔비전_모니터링, PJT_소형태양광_정산대행, TF_사업개발_KSGE2026
## TF, PJT, 협업 구분
| 구분 | TF | PJT | 협업 |
| 승인 | 필수 | 불필요 | 불필요 |
| 기간 | 4주 이상 장기 | 1주~3개월 단기 | 상시 |
| 특징 | 전사 중요 과제, 대표이사 승인, 복수 조직, 매출·신규 비즈니스 | 명확한 시작/종료 | 종료일 미정 |
| 정리 | 종료 시 삭제 | 종료 시 삭제 | 필요 시 유지 |
- 헷갈리면: “대표님이 알아야 하나?” → YES면 TF
## 채널 만들기
- **TF**: #[승인]TF_요청 채널에 양식(PM, 프로젝트명, 목적, 예상 기간, 관련 조직·인원, TF 필요 사유, 예상 리소스, 기대 효과) 작성 → CoS실 대표이사 승인 검토 → CoS실이 채널 생성. 2026년 2월 개편된 TF 운영 상세 가이드는 Notion 원문에 있어요.
- **PJT/협업**: Prefix 선택 → 이름 규칙 확인 → 채널 설명(목적/기간/담당) 작성(필수) → 관련자 초대
## 정리 시점
| 유형 | 정리 시점 | 담당 |
| TF_ | 완료보고 후 1~2주 | CoS실 |
| PJT_ | 프로젝트 종료 시 | 생성자 |
| 협업_ | 업무 종료 시 (선택) | 생성자 |
| 부서_ / 문의_ | 조직 변경 시만 | 각 부서 |
- 매월 말 CoS실이 방치 채널을 일괄 정리해요.
- 프로젝트가 끝났는데 소통이 계속 필요하면 협업_ 채널로 전환해요. (예: PJT_VPP입찰시장대응 → 협업_VPP_입찰운영)
- 기존 채널명도 규칙에 맞게 바꿔 주세요. 문의는 CoS실 노아 / #COS실_Front (최종 업데이트 2026.02.19)

## 명함 주고받기
- 받는 사람이 바로 읽을 수 있는 방향으로, 내용을 가리지 않게 두 손으로 공손하게 건네요. (영상은 Notion 원문)
## 내 손님을 맞을 때
1. 사무실 앞에 도착하면 본인에게 전화해 달라고 미리 안내해요. 초대한 사람이 도착 확인, 출입 맞이, 회의실 인솔까지 책임져요.
2. 10~15분 일찍 회의실을 잡고 디스플레이, 온도 등 준비를 마쳐요.
3. 시원한 커피, 물, 따뜻한 물 중 무엇을 드실지 여쭤보고 드려요. (로비 미니냉장고)
4. 미팅이 끝나면 의자, 리모컨, 보드마커 원위치와 에어컨 끄기까지 정리해요.
## 다른 팀원의 손님을 마주쳤을 때
1. “무슨 일로 찾아오셨나요?” 또는 “찾으시는 분 성함이 어떻게 되나요?”로 방문자를 파악해요.
2. “확인해보겠습니다, 잠시만 이곳에서 기다려 주시겠어요?”라며 로비나 복도에서 대기를 부탁해요.
3. 담당자에게 알려요. 미확인 방문자(대표님을 찾는 고객 등)는 CoS실에 즉시 연락해요.
