# 에너닷 생활백서 웹페이지

검색과 카테고리로 생활백서를 찾아보는 웹페이지예요. 내용은 `content` 폴더의 텍스트 파일에 들어 있어서, 코드를 몰라도 직접 고칠 수 있어요.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 디자인과 검색 기능 (보통은 손댈 필요 없음) |
| `content/01-start.md` | 처음 오셨나요? (자주 묻는 질문, 온보딩 미션, 협업툴) |
| `content/02-about.md` | 에너닷이 궁금하다면 (회사 정보, 미션, 팀 소개 등) |
| `content/03-space.md` | 공간이 궁금하다면 (오피스, 업무 공간, 휴식 공간) |
| `content/04-help.md` | 도움이 필요하다면 (결재 업무, 업무 지원) |
| `content/05-work.md` | 우리가 일하는 방식 (근태, 연차, 소통 등) |
| `content/06-fun.md` | 우리가 즐기는 방식 (복지, 타운홀데이, 동호회) |
| `assets/` | 로고 이미지 |

## GitHub Pages로 올리기 (처음 한 번)

1. GitHub에서 **New repository**를 만들어요. 이름은 예를 들어 `handbook`.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더(`index.html`, `content`, `assets`, `README.md`)를 모두 끌어다 놓은 뒤 **Commit changes**를 눌러요.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 Save를 눌러요.
4. 1~2분 뒤 같은 화면 상단에 주소(`https://아이디.github.io/handbook/`)가 나타나요. 이 주소를 직원들에게 공유하면 돼요.

> ⚠️ 무료 GitHub 계정의 Pages는 **주소를 아는 누구나 볼 수 있는 공개 사이트**예요. 비공개 저장소로 만들어도 Pages 주소는 공개돼요. 사내 정보(사업자 정보, 계좌, 접속 코드, 초기 비밀번호 등)가 들어 있으니, 회사 계정 로그인으로 접근을 막을 수 있는 방식(예: GitHub Enterprise의 비공개 Pages, Cloudflare Pages + Access)을 쓰거나 공개용으로 민감한 내용을 뺀 뒤 올려 주세요.

`index.html`을 컴퓨터에서 더블클릭해 열면 "내용 파일을 불러오지 못했어요"라고 나와요. 정상이에요. 웹 주소로 열면 잘 보여요.

## 내용 고치기

1. GitHub 저장소에서 `content` 폴더의 파일을 열고 오른쪽 위 ✏️(Edit) 버튼을 눌러요.
2. 내용을 고친 뒤 **Commit changes**를 눌러요.
3. 1~2분 뒤 웹페이지에 반영돼요. (안 보이면 새로고침)

### 작성 규칙

페이지 하나는 `@@`로 시작하는 줄부터 다음 `@@` 전까지예요.

```
@@ id=leave | cat=work | group=에너닷에서 일하는 법 | icon=🏖️ | title=연차/휴가 | url=https://app.notion.com/p/...
@summary 목록과 페이지 상단에 나오는 한 줄 설명
@kw 검색 키워드를 띄어쓰기로 (반차 월차 휴가 …)
## 소제목
일반 문장은 그냥 쓰면 돼요.
- 글머리표 항목
1. 번호 항목
[ ] 체크리스트 항목
> 인용(강조 문구)
! 노란 상자로 보이는 ‘꼭 확인’ 문구
| 머리글1 | 머리글2 |
| 내용1 | 내용2 |
@note 페이지 맨 아래 회색 메모
```

| 표기 | 의미 |
|---|---|
| `**굵게**` | 굵은 글씨 |
| `` `코드` `` | 회색 박스 글씨 (코드, 번호 등) |
| `[[페이지id]]` | 다른 페이지로 가는 링크 (예: `[[flex]]` → 플렉스 페이지) |
| `https://…` | 자동으로 링크가 돼요 |
| `%%` 로 시작하는 줄 | 메모용. 화면에 안 보여요 |

머리줄(`@@`) 항목:

- `id`: 주소에 쓰이는 영문 이름. 페이지마다 달라야 하고, 영문·숫자·하이픈(-)만 써요. 바꾸면 기존 `[[id]]` 링크도 같이 바꿔야 해요.
- `cat`: 카테고리. `start`, `about`, `space`, `help`, `work`, `fun` 중 하나.
- `group`: 카테고리 안의 작은 묶음 이름.
- `icon`: 이모지 하나. / `title`: 페이지 제목. / `url`: Notion 원문 주소.
- `new=1`을 붙이면 목록에 ‘업데이트’ 표시가 떠요. (예: `… | url=… | new=1`)

`@check` 줄은 “내용 확인 필요” 노란 상자와 첫 화면 상단 안내를 띄워요. 확인이 끝나면 그 줄을 지우면 표시가 사라져요. 모두 지우면 상단 안내도 사라져요.

### 새 페이지 추가하기

원하는 카테고리 파일 맨 아래에 `@@` 줄부터 새로 써요. 파일 이름이나 순서는 화면 배치에 영향을 주지 않고, `cat`과 `group` 값으로 위치가 정해져요. 같은 `group` 안에서는 파일에 적힌 순서대로 나와요.

### 첫 화면 바로가기 버튼과 기타 설정

`index.html`에서 아래 부분을 찾아 고쳐요.

- `const SIT=[ … ]`: “이럴 땐 여기” 버튼. `['버튼 문구','페이지id']` 형식이에요.
- `const CATS=[ … ]`: 카테고리 이름과 순서.
- `const SNAPSHOT=`: 첫 화면 맨 아래 문구.
- `const FILES=[ … ]`: 내용 파일을 새로 추가했다면 여기에도 파일 이름을 넣어요.
